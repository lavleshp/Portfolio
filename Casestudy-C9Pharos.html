C9Pharos Platform

Read Case Study

Overview

C9Pharos is an enterprise cybersecurity platform designed to help organizations monitor website health, SSL certificates, uptime, domain information, vulnerabilities, email breaches, and security intelligence from a single application.

The Challenge

Cybersecurity products often overwhelm users with technical terminology, fragmented workflows, and data-heavy dashboards. Users were forced to switch between multiple disjointed tools to monitor critical infrastructure.

The Goal: Not just designing beautiful screens, but transforming complex security data into a unified, instant-read mobile experience that IT professionals could understand within seconds.

My Role

As the sole designer on the project, I was responsible for bridging business objectives, technical constraints, and user needs to deliver a cohesive product.

UX Strategy & Features

Decreasing Time-to-Value

Gradual Onboarding

Instead of overwhelming users with every capability at once, the onboarding introduces one core feature per screen. This progressive approach helps users understand the product faster while reducing cognitive load.

Design Reasoning: Progressive disclosure improves feature discoverability, builds confidence, and reduces first-session friction.

Actionable insights at a glance

Dashboard & Monitoring

The dashboard is engineered for split-second decision-making. Eschewing complex data tables, critical information is abstracted into highly legible, reusable status cards.

From raw data to remediation

Vulnerability Assessment

Security reports notoriously paralyze users with lengthy technical findings. I redesigned this flow to aggregate data into a top-level Overall Risk Score, supported by color-coded Severity Categories.

Design Reasoning: Visualizing risk allows users to prioritize critical remediation immediately, while nested panels house the granular, actionable resolution recommendations for developers.

PwnCheck Experience Design

PwnCheck enables users to scan their emails against known public data breaches. This flow was meticulously designed around three distinct emotional states to manage user anxiety and drive clear action.

1. Search State

A hyper-focused, minimal interface designed solely to encourage input. Extraneous elements are removed to streamline querying.

2. Safe State

Delivering positive reinforcement. Uses distinct, reassuring green visual cues and calming copy to confirm data remains uncompromised.

3. Breached State

Designed to prevent panic. Uses strict visual hierarchy to highlight what data was leaked and provides immediate mitigation steps.
